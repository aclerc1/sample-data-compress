# sample-data-compress
C implementation of a data compression algorithm to compress a given data buffer of bytes.

# Quick start
1. Review `docs/challenge.pdf` for details of the data compression challenge.
2. Review `docs/solution.pdf` for details of the implemented solution.
2. Build and run the code in `src/main.c`.

# Project structure
```
./sample-data-compress
├── docs
│   ├── challenge.pdf
│   └── solution.pdf
└── src
    └── main.c
```

# Build and run
```
gcc src/main.c -o main.o
```
```
./main.o
```
